    Class ThemeValidator

    Main theme validation class for comprehensive theme validation.

    This class provides a complete validation system for Aether themes, including schema validation, content validation, accessibility checking, and performance analysis.

    validateTheme

    • validateTheme(
          theme: ThemeSchema,
          options?: ValidationOptions,
      ): Promise<ValidationResult>

      Validates a complete theme schema with comprehensive checks.

      This method performs a complete validation of the theme including:

      • Schema structure validation
      • Content validation (colors, typography, spacing, animations)
      • Accessibility validation (contrast ratios, WCAG compliance)
      • Performance validation (animation durations, file sizes)
      • Custom validation rules

      Parameters

      • theme: ThemeSchema

        The theme schema to validate

      • Optionaloptions: ValidationOptions

        Optional validation configuration

      Returns Promise<ValidationResult>

      Promise resolving to validation result with scores and errors

      Example

      const validator = new ThemeValidator();

      // Basic validation
      const result = await validator.validateTheme(themeSchema);

      // Advanced validation with all checks
      const result = await validator.validateTheme(themeSchema, {
        validateAccessibility: true,
        includeWarnings: true,
        customRules: [
          {
            name: 'brand-colors',
            validate: (theme) => {
              const errors = [];
              if (!theme.colors.brand) {
                errors.push({
                  message: 'Brand color is required',
                  path: 'colors.brand',
                  severity: 'error'
                });
              }
              return errors;
            }
          }
        ]
      });

      // Handle validation result
      if (result.isValid) {
        console.log('Theme validation passed!');
        console.log(`Accessibility: ${result.accessibilityScore}/100`);
        console.log(`Performance: ${result.performanceScore}/100`);
      } else {
        console.log('Validation failed:');
        result.errors.forEach(error => {
          console.log(`- ${error.message}`);
        });
        result.warnings.forEach(warning => {
          console.log(`⚠️ ${warning.message}`);
        });
      }
